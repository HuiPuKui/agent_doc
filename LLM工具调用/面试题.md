# LLM 工具调用面试题

### 1. 什么是 Function Calling？原理是什么？

Function Calling：开发者用 JSON schema 把工具描述好传给模型，模型判断需要调工具的时候不输出自然语言，而是直接输出一段结构化的 tool_calls JSON，告诉你「我要调用哪个函数、参数是什么」，你的代码拿到这段 JSON 去真正执行，把结果塞回对话，模型再生成最终答案。

整个流程的本质是两轮对话：第一轮模型说「我需要调这个工具」，你去执行，第二轮模型拿到执行结果说「答案是这个」。

核心的设计是：模型全程只做决策，执行的事情一律由宿主代码完成，职责分得很清楚。

### 2. LLM 是如何学会调用外部工具的？

训练层面靠两个阶段：
* SFT（监督微调）：给模型喂大量「工具调用示范对话」，让他通过模仿学会「看到工具描述 -> 判断要不要调 -> 输出结构化 JSON 请求」这整套流程
* RLHF（基于人类反馈的强化学习）：收集人类对「哪种回答更好」的判断，训练一个打分器，再用这个分数反复调整模型，让它学会什么时候不应该调工具

运行层面，每次请求时，代码将工具描述传给模型，模型如果判断需要工具，就输出一段结构化的 tool_calls JSON，你的代码拿到这段 JSON 去真正执行，把结果塞回对话，模型再给出最终答案。

**模型全程只是在「下指令」，真正执行工具的是你的代码，不是模型本身。这套「模型决策、代码执行」的运行时机制，就是我们常说的 Function Calling**

### 4. 什么是 MCP（模型上下文协议）？讲讲它的核心内容？

MCP 是 Anthropic 在 2024 年底推出的开放协议，主要解决「模型接工具太碎片化」的问题

MCP 的思路是把这件事标准化：工具提供方按协议实现一个 Server，任何支持 MCP 的 AI 客户端就能直接接进来，一次实现到处复用。

协议定义了三类能力：Tools 用于执行有副作用的操作，Resources 是只读数据，Prompts 是提示词模板，底层通信用 JSON-RPC 2.0 

### 5. MCP 由哪几部分组成？

角色
* Host：AI 应用本身
* Client：Host 中负责和 Server 通信的模块
* Server：工具提供方实现的独立进程，一个 Host 可以连接多个 Server

能力
* Tools：有副作用的操作
* Resources：只读数据
* prompt：可复用的提示词模板

协议
* JSON-RPC 2.0（stdio、Streamable HTTP）

### 6. MCP 和 Function Calling 有什么区别？有没有实际跑过 MCP？

Function Calling 是「调用语言」，定义的是模型怎么表达「我要调用哪个函数、参数是什么」

MCP 是协议，定义工具怎么标准化打包、注册和被 AI 客户端发现

MCP 底层是用 Function Calling 来触发工具调用，只是在它之上加了一套工具管理框架，让工具实现一次，到处复用。

### 7. Function Calling 也属于工具调用，请问什么场景下使用 Function Calling，什么场景下使用 MCP？

判断的核心问题就一个：这个工具会不会在这个应用之外被用到？会的话，把它封装成 MCP Server 是更长远的选择

此外，做 Agent 系统的话更应该选 MCP，工具来源多、数量大，手写 Function Calling 的维护成本会让代码变得难以管理。

### 8. 为什么有些特定的推理模型不支持 MCP 协议？

根本原因是两者的生成范式有冲突。

推理模型：给出答案之前会先跑一段完整的「推理」，这个 thinking 过程是一次性连续生成的，不能中途打断

工具调用：天然是多轮交互，模型输出调用请求、暂停等工具执行、拿到结果继续生成。

MCP 底层是 Function Calling 驱动的，推理模型 Function Calling 支持不好，MCP 自然也用不了

后面的模型都找到了折中方案，让工具调用发生在思考阶段结束之后，保证思考过程还是一次性完整生成的。

### 9. Skill 是什么？

SKILL 是把 「指令、脚本、模板」一体化打包成可复用能力包的机制，关键在于 Agent 能自动发现、按需加载、在需要时调用里面的脚本资源。

和 prompt 的区别：SKILL 能被 Agent 自动发现和加载
和 MCP 工具的区别是：MCP 给 Agent 提供外部工具和数据的访问能力，SKILL 是教 Agent 拿到这些工具和数据之后怎么用

三层加载：只读元数据 -> 按需加载指令 -> 用到时取资源

### 10. MCP 和 Agent Skill 有什么区别？

MCP：「Agent 怎么获得外部能力」
* 把外部工具标准化封装成服务，Agent 能通过 MCP 查数据、调接口、读写文件

SKILL：「Agent 拿到这些能力之后，该按什么步骤、什么标准来完成任务」
* 把完成某类工具的知识和流程打包成可复用的模块

### 11. Function Calling、Skill、MCP 这三个有什么区别？

Function Calling：是最底层的调用协议，解决的是「模型怎么调函数」，模型输出结构化 JSON 告诉程序该调哪个函数、传什么参数

MCP：在 Function Calling 之上做工具标准化，解决「工具怎么暴露给模型」，一次实现到处复用

SKILL：做知识和流程的封装，解决「拿到工具之后按什么流程完成任务」，把执行步骤、标准、脚本、模版打包成可复用模块

### 12. 什么是 A2A 协议？它和 MCP 协议的区别是什么？

A2A 解决多个 AI Agent 之间怎么互相通信协作的问题。

MCP 解决单个 AI Agent 怎么连工具和数据
