# Agent 面试题

### 1. 什么是 Agent? 与大模型有什么本质不同？

大模型是每次你问他一个问题他回答一个问题，每次都是独立的

Agent 是有主动性的，Agent 以大模型作为底层大脑，你给他一个目标，他会自己进行分析、拆解，通过调用工具、记忆管理来一步步感知上下文环境，直到完成。

### 2. Agent 的基本架构由哪些核心组件构成

* LLM：底层大模型，整个系统的大脑，负责任务理解和决策
    * system prompt: 模型的角色提示词很重要
    * 推理能力
    * 上下文窗口

* 工具：让 Agent 和外部世界交互，搜索、执行代码、调用API等
    * description：工具定义很重要，一定要描述清楚

* 记忆：让 Agent 在任务执行过程中保持状态  
    * 短期记忆
    * 长期记忆

* 规划模块：负责把复杂目标拆解成可执行的步骤
    * CoT：Chain of Thought 思维链
    * ToT：Tree of Thought 思维树
    * Plan-and-Execute、ReAct 一般结合使用

### 3. Workflow，Agent，Tools 这三个的概念和区别介绍一下？

* Tools: 最小的能力单元，封装好的可调用函数
    * 给大模型看的函数
    * 有描述来描述函数作用

* Agent: 一个完整的决策系统
    * LLM 作为大脑
    * 自己判断何时执行 Agent

* Workflow: 更上层的编排框架，把 Agent、LLM、Tools 组织成一条确定性流程
    * 提示链
    * 路由
    * 并行化
    * 编排者-工人（Orchestrator-Workers）
    * 评估者-优化者（Evaluator-Optimizer）
